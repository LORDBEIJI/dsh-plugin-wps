# 定制版 ppt-master

让 Agent 生成**原生可编辑 PPTX** 的技能包，含两处本地定制。

本目录**不包含** ppt-master 的代码 —— 它只保存定制差异。官方代码在安装时从上游获取，
这样你拿到的是最新官方功能 + 定制条款，而不是一份会过期的快照。

## 两处定制改了什么

### ① Pre-Flight Intake（开工前先问两件事）

**位置**：`SKILL.md` 新增章节，`workflows/routing.md` 新增对应例外条款

**动机**：上游把这两个选择交由默认值决定。默认值一旦不合意，代价是整轮规划返工。

**行为**：路由判定之后、所选流程第 1 步之前，先问用户：

1. 确认方式 —— 在**浏览器页面**里确认，还是**直接在对话里**确认？
2. 生成深度 —— 走**完整流程**（两次确认 + spec/lock + 质量门禁），还是**快速生成**？

**保护条款**（避免它变成烦人的反复追问）：

- 用户已经表达过的答案会被跳过 —— 明确指令永远优先
- 每次运行最多问一次
- 未回答则回落到上游默认值
- 它不替代 Stage-1 / Stage-2 确认，该走的门禁照走

### ② Cost Discipline（成本纪律）

**位置**：`SKILL.md` 新增章节，`workflows/routing.md` 新增指针条款

**动机**：来自一次真实失败 —— 一次"快速生成"既不便宜（执行成本没省）又漏掉了配图。

**记录的成本事实**：动手前必须读取的契约文档约 **150 KB**，3 页和 20 页付的一样多，
所以**单页成本随页数下降**，低于约 8 页时固定成本占主导。

**三条规则**：

1. **Quick 不是省钱选项** —— 它省流程（确认页、spec/lock、备注），**不省执行**。
   它真正牺牲的是**可复用性**：没有 lock 可改，后续换风格只能从头重跑。
2. **成本或速度永远不能砍掉内容需求** —— 视觉锚定是内容而非装饰。当受众必须
   "认出／体验／比较某个外部实物"时（史料、真实产品、具体地点、人物、文物），
   这份 deck 就需要实物图片；为求快而省略，会付出同样的契约成本却交付一份失职的作品。
3. **开工前说清成本形状** —— 什么固定、什么随规模变，让用户拿真实数字做选择；
   若有更轻的方法更合适，要在开工前说，而不是事后。

详细条款文本与重新应用步骤见 `overlay/LOCAL-CHANGES.md`。

## 安装

```bash
node skill/ppt-master/install.mjs
```

脚本会：

1. 检查 `~/.dsh/skills/ppt-master`，未安装则从上游克隆（约 80 MB，需要几分钟）
2. 用 `overlay/` 覆盖三个文件
3. 运行官方完整性门禁验证
4. 打印结果

选项：

```bash
node skill/ppt-master/install.mjs --yes    # 跳过所有确认提示
```

**依赖**：`git`（必需）；`python` / `python3` / `py`（可选，用于门禁校验，缺省会跳过并提示）。

## 使用

安装后无需重启 —— DSH 会热加载 `~/.dsh/skills` 下的技能。

在会话里说：

```
用 ppt-master 做一个关于 <主题> 的 PPT
```

定制生效后的实际流程：

1. 先问你**确认方式**和**生成深度**（Pre-Flight Intake）
2. 同时说明**成本形状**（页数与固定成本的关系）—— 页数偏少时它会建议换更轻的方法
3. 按选定路由继续；若走 Default，则进入 Stage-1 / Stage-2 确认

**排除该技能**（配置图像生成后端，可选）：技能支持 15 个图像后端，配置写在用户级
`.env` 里，与技能目录分离：

```bash
# ~/.ppt-master/.env
IMAGE_BACKEND=zhipu
ZHIPU_API_KEY=你的key
```

⚠️ **不要**把 `.env` 提交进任何仓库。

## 故障处理

| 现象 | 处理 |
|---|---|
| 门禁校验失败 | overlay 与当前上游版本不兼容。删除技能目录重新克隆，然后按 `overlay/LOCAL-CHANGES.md` 重新生成 overlay |
| DSH 提示找不到该技能 | 确认 `include:skill-filesystem` 插件已启用（它负责扫描 `~/.dsh/skills`） |
| clone 太慢 | 上游约 80 MB / 13000 文件，属正常。可用 `--depth 1`（脚本已默认使用） |
| 想用未定制的官方版 | 删除 `~/.dsh/skills/ppt-master` 后重新 clone 上游即可 |

## 与 dsh-wps 插件的关系

**两者独立，没有代码依赖。**

- `dsh-wps` 让 Agent **操作本机 WPS**（打开、创建、读取、转 PDF）
- `ppt-master` 让 Agent **做出高质量的 PPTX**

推荐组合用法：用 ppt-master 生成 PPTX，再用 dsh-wps 的 `wps_open` 打开给你看、
`wps_convert_pdf` 导出 PDF 校验。两者通过**文件路径**衔接，不存在耦合。
